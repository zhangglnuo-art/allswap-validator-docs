# Architecture Overview

**AllSwap MultiChain Memo & Address Validator** is an open-source, zero-dependency verification suite maintained by [AllSwap Security Labs](https://allswap.io) to prevent irreversible cross-chain settlement errors across 46+ blockchain networks.

- **Interactive Online Suite**: [https://allswap.io/tools/address-validator](https://allswap.io/tools/address-validator)
- **AllSwap Cross-Chain Aggregator**: [https://allswap.io](https://allswap.io)
- **GitHub Repository (MIT)**: [https://github.com/zhangglnuo-art/multichain-memo-address-validator](https://github.com/zhangglnuo-art/multichain-memo-address-validator)

## Quick Start

```bash
npm install nuxt-crypto-address-validator
# or
npm install fastify-multichain-address
```
